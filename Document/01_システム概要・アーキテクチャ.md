# 01. システム概要・アーキテクチャ

## 1. システム概要
本システムは、300人規模の中規模組織における円滑な業務報告、ナレッジ共有、組織横断の活動可視化、および過重労働防止を目的とした「Web週報システム」のプロトタイプです。

### 1.1 主なターゲットと課題解決
- **全社・部門の可視化**: 本部 ＞ 部 ＞ 課 の階層組織ツリーにより、上位組織をクリックするだけで配下全メンバーの週報を串刺し閲覧可能。
- **報告の効率化**: マークダウン入力、リアルタイムプレビュー、下書き保存、提出状態管理により、ストレスのない週報作成を実現。
- **労務・稼働マネジメント**: 週報に実働稼働時間を記録し、マネージャーが配下メンバーの負荷状況を「積み上げグラフ」で一目で把握。36協定・過重労働（週45時間超）の早期発見を支援。

## 4. ロール（権限）モデル仕様

システム内には3段階のロール（`Role`）を設けています。

| ロール (`Role`) | 主な対象者 | 権限範囲 |
| :--- | :--- | :--- |
| **`ADMIN`** (管理者) | システム管理者、人事総務 | - 全社・全組織の全週報の閲覧・検索<br>- 階層部門マスタの作成・編集・削除<br>- ユーザーマスタの登録・所属変更・権限変更・初期化<br>- 全社全メンバーの稼働時間積み上げグラフの閲覧<br>- 自週報の作成・更新 |
| **`MANAGER`** (マネージャー) | 本部長、部長、課長、リーダー | - 全社・自部門・メンバー週報の閲覧・検索<br>- **配下メンバー稼働集計（積み上げグラフ）の閲覧**（自部門および配下子部門のメンバーのみ再帰抽出）<br>- 自週報の作成・更新 |
| **`MEMBER`** (一般メンバー) | 一般従業員 | - 全社・自部門・メンバー週報の閲覧・検索<br>- 自週報の作成・下書き・更新（実働稼働時間入力含む）<br>※ 管理画面および稼働集計画面へのアクセスは不可（ガード付き） |
