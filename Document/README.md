## 🛠 システム概要ハイライト

- **対象規模**: 従業員 300 名規模
- **主要機能**:
  - 本部 ＞ 部 ＞ 課 の**多階層組織ツリー**による週報串刺し・フィルタリング
  - **マークダウン入力 & リアルタイムプレビュー**対応の週報エディタ
  - **実働稼働時間の登録**と、マネージャー向け**積み上げグラフ（Stacked Bar Chart）**による過重労働モニタリング
  - **ロール別アクセス制御**（ADMIN / MANAGER / MEMBER）と管理者専用マスタ画面
