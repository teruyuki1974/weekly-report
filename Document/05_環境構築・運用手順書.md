# 05. 環境構築・運用手順書

## 1. 開発環境の前提要件

- **OS**: Windows 11 / WSL2 (Ubuntu 24.04 / 26.04)
- **Node.js**: v20 以上 (推奨: LTS v24.21.0)
- **パッケージマネージャー**: npm
- **コンテナランタイム**: Docker Engine & Docker Compose

---

## 2. 初回セットアップ手順

### 2.1 リポジトリディレクトリへ移動
```bash
cd /home/tfukuda/weekly-report
```

### 2.2 依存関係のインストール
```bash
npm install
```

### 2.3 PostgreSQL コンテナの起動
リポジトリ直下の `docker-compose.yml` を使用して PostgreSQL 16 コンテナを起動します。

```bash
docker compose up -d
```
> ※ コンテナ名: `weekly-report-db`、ポート: `5432:5432`

### 2.4 データベースの初期化 & マイグレーション
Prisma スキーマをデータベースに反映します。

```bash
npx prisma db push
npx prisma generate
```

### 2.5 初期シードデータの投入
組織階層マスタ、デモユーザー、および複数週分の稼働時間入り週報データを投入します。

```bash
npx prisma db seed
```

---

## 3. 開発サーバーの起動

```bash
npm run dev
```

起動後、Windows側のWebブラウザから以下のURLにアクセスできます。

- **週報システム**: [http://localhost:3000](http://localhost:3000)
- **ログイン画面**: [http://localhost:3000/login](http://localhost:3000/login)

---

## 4. プロダクションビルドの検証

ビルドおよびTypeScript型チェックを実行する場合：

```bash
npm run build
```

## 6. よくあるトラブルシューティング

### Q1. Dockerソケットのパーミッションエラー (`permission denied while trying to connect to the docker API`)
```bash
sudo chmod 666 /var/run/docker.sock
```
または現在のユーザーを `docker` グループに追加してシェルを再起動してください。

### Q2. Prisma スキーマを変更したのに反映されない
```bash
npx prisma db push
npx prisma generate
rm -rf .next
npm run dev
```
キャッシュクリアを行った上で開発サーバーを再起動してください。
